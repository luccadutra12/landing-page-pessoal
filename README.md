# landing-page-pessoal

Portfólio simples criado como atividade hands-on — páginas responsivas em HTML, CSS e Bootstrap.

Como abrir localmente:

1. Abra a pasta do projeto no seu editor (VS Code).
2. Abra `index.html` no navegador (clique com o botão direito -> "Open with Live Server" ou apenas arraste o arquivo para o navegador).

Arquivos principais:

- [index.html](index.html#L1) — Página Home
- [about.html](about.html#L1) — Página Sobre Mim
- [projects.html](projects.html#L1) — Projetos em destaque
- [contact.html](contact.html#L1) — Formulário de contato

Deploy (opcional): publique o conteúdo no GitHub Pages a partir da branch `main`.
